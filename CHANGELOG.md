# Changelog

All notable changes to FamilyCollection will be documented in this file.

## [v0.3.0] - 2026-09-04

### Added
- Isolated synthetic demo environment for public testing and screenshots.
- Public project screenshots for the dashboard, books, item details, and storage management.
- Support for deployment behind a reverse proxy under a URL subpath.

### Improved
- Public documentation and deployment guidance.
- Demo books and synthetic demo content.
- Collection UI consistency and presentation.
- Image URL handling across collection detail and edit views.

### Fixed
- Item image URLs when FamilyCollection is deployed under a subpath.
- Demo navigation and image handling in subpath deployments.
